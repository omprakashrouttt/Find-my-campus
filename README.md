## Project Overview
Find My Campus is a simple and intuitive web project designed to help new students and visitors navigate the SRM University campus with ease. Users can search for buildings, departments, and amenities, and get turn-by-turn directions. No complex setup—just open and explore!

## Features
- Interactive map with clickable markers for buildings and facilities
- Search bar to quickly find any location on campus
- Step-by-step directions between selected points
- Responsive design for both mobile and desktop
- Live distance and estimated time display

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Mapping**: Leaflet.js, OpenStreetMap
- **Deployment**: Netlify (Static site)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/omprakashrouttt/Find-my-campus.git
   cd Find-my-campus
   ```
2. Open `index.html` in your browser, or visit the live demo: [findmycampus.netlify.app](https://findmycampus.netlify.app/)

*No build tools or dependencies required.*

## Usage
1. Enter a building or facility name in the search bar
2. Click a result to view its location on the map
3. Select **Directions**, choose start and end points, and follow the route
